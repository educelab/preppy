# Specification: Toolchain spike (de-risk the approach)

**Track ID:** toolchain-spike_20260706
**Type:** Chore
**Created:** 2026-07-06
**Status:** Draft

## Summary
Validate the whole delivery+viewer bet on real `mvs` data — before building any
pipeline or viewer infrastructure. Produce throwaway assets and a throwaway page
that prove gltfpack + toktx + three.js deliver camera-preserving band switching
of ~8K textures without OOM.

## Context
The project is pivoting off DPO Voyager to a custom three.js viewer fed by
meshopt geometry + KTX2 textures (see ADR-0001, ADR-0002). Several assumptions
underpin that pivot; this spike tests them cheaply so we don't discover a
showstopper after committing to the build.

## Acceptance Criteria
- [ ] `gltfpack` produces a geometry-only, error-bounded-decimated, meshopt-
      compressed `.glb` from one `mvs` OBJ; it loads in three.js.
- [ ] `toktx` encodes one 8K source texture to `.ktx2` (both UASTC and ETC1S)
      with mipmaps; both load via `KTX2Loader`.
- [ ] A throwaway three.js page orbits the model and swaps bands **without
      resetting the camera** — demonstrated for both the same-geometry
      (texture-only) and different-geometry (mesh-swap) cases.
- [ ] Several 8K KTX2 bands coexist in memory without OOM on a mid-range device.
- [ ] Source OBJs have no normals (`vn=0`); confirm the chosen normal strategy
      (bake vs `computeVertexNormals()`) lights correctly.
- [ ] Rough decimation deviation is spot-checked so measurement will be viable.

## Dependencies
None. This is the first track; everything else depends on its findings.

## Out of Scope
Production code, packaging, the manifest schema, measurement UI polish. This is a
throwaway spike — findings feed the tuning parameters, not shippable artifacts.

## Technical Notes
Use the `~/temp/herculaneum/retexture_final/mvs` set (bands `2_*`, `4_*`, `5_*`).
The `5_spectral_rgb` / `5_spectral_ir1050` pair is the only byte-identical
