# Specification: Delivery pipeline (meshopt geometry + KTX2 + manifest)

**Track ID:** delivery-pipeline_20260706
**Type:** Feature
**Created:** 2026-07-06
**Status:** Draft (revised 2026-07-07 after toolchain spike + deliverables grill)

## Summary
Rework `dri-voyager-preppy` to turn source OBJs + textures into **one
self-contained `.glb` per variant** (meshopt geometry + embedded KTX2) plus a
viewer-native per-object manifest — replacing the Voyager `.svx.json` /
`obj2gltf` + `gltf-pipeline` path.

## Context
An object is imaged as several **variants** (RGB, IR, PGS, …), each a mesh with
one or more large, exotic textures. Per ADR-0002 (amended), each variant ships as
a single self-contained glb; the per-object manifest lists a flat `variants[]`.
Correct colorspace conversion, accuracy-preserving decimation, and the spike's
hard requirements (UVs kept "used", `KHR_texture_transform`, node transform,
atlas dilation) are constraints. See `spike/FINDINGS.md` and Workstream A of
`docs/implementation-plan.md`.

## User Story
As a DRI operator preparing an object for the archive, I want one command that
emits a self-contained glb per variant + a correct manifest, so the object is
ready for the `<dri-viewer>` widget without manual asset fiddling.

## Acceptance Criteria
- [ ] Given the `mvs` example config, the pipeline emits a valid per-object
      manifest + one self-contained `<prefix>_<suffix>.glb` per variant
      (+ thumbnail) in a per-object output directory.
- [ ] A variant's texture(s) are resolved **transitively** from its OBJ's
      `map_Kd` (one or many — multi-chart UV supported); each variant glb embeds
      all its KTX2 textures (`KHR_texture_basisu`).
- [ ] Exotic textures (CIELab, 16-bit) convert to correct 8-bit sRGB before KTX2.
- [ ] Optional atlas **no-data dilation** (`nodataFill` cascade) removes fill
      bleed before encoding.
- [ ] Geometry is meshopt-compressed and decimated (`-si ≈ 0.2`) within a
      deviation budget, validated (Hausdorff); UVs kept "used" so the atlas is not
      corrupted.
- [ ] Manifest carries `title`, `inventory`, `description`, `credit`, `date`,
      `units:"cm"`, and a flat `variants[] {id,label,uri,default}` with optional
      per-variant overrides.
- [ ] Content-hash cache-busting (`--hash-names`, default on) with `--prune`;
      manifest/`index.json` stay stable-named.
- [ ] `voyager-preppy -h` still runs (CI smoke test stays green).

## Dependencies
Depends on **toolchain-spike_20260706** (GO; validated gltfpack/ktx settings,
`-si 0.2` budget, ETC1S default, normals-in-viewer, and the UV/transform/node
requirements).

## Out of Scope
The viewer widget; back-catalog migration; two-tier LOD; rendered 3D thumbnails
(texture-crop thumbnails only for now); shared-geometry asset sharing (dropped,
ADR-0002 amended).

## Technical Notes
New system deps: `ktx` (**KTX-Software ≥ v5**, `ktx create` — `toktx` removed),
`gltfpack`, and `gltf-transform` (Node, embeds KTX2 → variant glb). Keep
`mogrify`; retire `obj2gltf`/`gltf-pipeline`. New modules `texture.py`,
`geometry.py`, `assemble.py`, `manifest.py` (replaces `voyager.py`); keep
`obj_helpers.parse_materials` (**no** `geometry_fingerprint` — grouping dropped);
rewrite `apps/file_prep.py`. Python floor 3.11+; Node 20+.

## Risks and Mitigations
| Risk | Impact | Mitigation |
| --- | --- | --- |
| Multi-material OBJs untested by the spike (only single-material proven) | High | **Validate one real multi-material `mvs` OBJ end-to-end first** before batch work |
| gltf-transform round-trip may drop meshopt / `KHR_texture_transform` | Med | Verify extensions survive embed; assert in a test |
| basis encoding non-determinism | Low | Hash **inputs+config**, not output (decided) |
